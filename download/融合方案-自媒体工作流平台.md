# AI 搜索打造自媒体工作流平台 · 融合升级方案 v4.0

> 基于 AI 搜索做情报底座，图文 + 视频双生产线，融合 wewrite / huashu-motion / huashu-art-motion / dsh-imagegen-video / dsh-agnes-multimodal / pi-ai 六大外部生态。
> 本方案回应五点反馈：①雷达×灵感池冗余 ②交互堆叠混乱 ③视频模型接入缺失 ④pi-ai/Agnes 供应商化 ⑤wewrite 模板未使用。

## 二、新信息架构（6 Tab → 4 Tab）

```
┌─ 情报中心（雷达×灵感池融合）────────────────────────────┐
│ 左列：话题雷达管理 + AI 即时搜索（写前情报）              │
│ 中列：早报生成/历史 + claims 溯源账本                     │
│ 右列：选题池（AI 刷新灵感 / 手动入池 / 搜索一键转选题 /    │
│       早报一键转选题）→ 「去创作」直达图文线              │
└─────────────────────────────────────────────────────────┘
┌─ 创作台（双生产线，顶部切换）───────────────────────────┐
│ [图文线] 选题→人格→主题(18+)→六步流水线→Run详情          │
│          动作分组：改稿飞轮 | 一稿多发 | 排版预览(18主题)  │
│          | 发布三级降级                                   │
│ [视频线] 分镜工作台（可视化卡片流+时间线，学 dsh 工作台）  │
│          三通道：motion 商业片 / art 艺术动画 / AI 模型    │
│          → TTS 口播 → ffmpeg 合成 → 成片播放/下载         │
└─────────────────────────────────────────────────────────┘
┌─ 插件生态（社区技能 + 插件中心合并）────────────────────┐
└─────────────────────────────────────────────────────────┘
┌─ 设置中心（供应商中枢，5 卡）───────────────────────────┐
│ LLM | 搜索 | 生图 | 视频(新) | Agnes 账号池(新) + 风格定位 │
└─────────────────────────────────────────────────────────┘
```

**交互拆分原则**：AI 搜索归情报中心（情报是它的产出）；图片生成归图文线 run 详情（封面场景）；视频生成归视频线工作台；图文排版预览归图文线。每个功能一个归位，不再堆叠。

## 三、供应商抽象（学 dsh 渠道体系 + pi-ai 统一 API 思想）

```
ProviderKind: LLM | SEARCH | IMAGE | VIDEO          (IMAGE/VIDEO 补全生成契约)
├─ yuanbao-search（搜索，已有）
├─ zai-llm / custom-openai（LLM，已有）
├─ zai-image（生图，已有）→ 补 generate() 契约
├─ agnes-llm   ┐
├─ agnes-image ├ 三 provider 共享一个 AgnesAccountPool 单例
├─ agnes-video ┘ （多账号轮询 + RPM 滑动窗口 + 429 熔断 + 失败换号）
└─ pi-ai-llm（评估引入 @mariozechner/pi-ai：15+ 供应商统一 API）
```

**Agnes 账号池设计**（源自 dsh-agnes-multimodal 实测协议）：
- 端点：国内 `https://api.agnes-ai.cn/v1` / 国际 `https://apihub.agnes-ai.cn/v1`，OpenAI 兼容 + Bearer
- 模型：`agnes-2.5/3.0-flash`（文本）、`agnes-image-2.1/2.5-flash`（图片）、`agnes-video-2.5-flash`（视频 720P 4-12s）
- 调度：图片滑动窗口 RPM（默认 20/60s/号）；视频 1 任务/分/号（记账占用）；连续 429/401 熔断 30s；失败指数退避换号
- 设置：账号行（站点分段+密钥掩码+测试按钮+启停）、状态卡（可用号数/图片并发/视频速率）、模型三选
- 视频协议做成可配置模板（两上游仓库轮询端点不一致，以实测为准）

## 五、wewrite 集成（P0，直接回应批评）

- **18 主题**：`repos/wewrite/.../themes/*.yaml` → 转换脚本 → TS 主题注册表（含 colors 调色板 + base_css + darkmode）
