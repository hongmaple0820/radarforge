# 0002 — 视频通道默认 auto

> 状态：已接受（用户拍板 2026-11-05，内容质量方案决策③）
> 溯源：commit `4825f55`（「决策①③默认值落地」）；`src/lib/runtime/video.ts:63,536`

## 背景

视频合成通道原默认 `local`（纯本地 ffmpeg 渲染，零 AI 视频片段），Agnes i2v 需要用户手动切。问题：多数用户不会知道要切，免费 AI 视频能力等于不存在；而 Agnes 是免费池，失败率受队列时段影响大，直接默认 `agnes` 又会在满载时段整片失败。

## 决策

- `VideoChannel = "local" | "agnes" | "auto" | "hybrid"` 四值
- **默认 `auto`**：Agnes 就绪则优先 agnes，未配置/提交失败按镜回退 local（诚实留痕，降级不消失）
- `hybrid`（后补）：部分镜 model + 部分镜 code 的混合模式——Bash 单调用 10 分钟窗口下「1 model + 2 code」最小验证方法论的产物

## 实证

auto 回退链在三轮 i2v 验收中按设计工作：周末队列满载时按镜诚实兜底成片，工作日上午分镜 1 次提交即成功（`#1:i2v 3.4s` 入片）。

## 后果与不变量

- 免费池能力默认可达，失败代价被按镜回退控制住
- 通道语义扩任何新值前先读本 ADR；`auto` 的回退必须保持按镜粒度与留痕，不允许整片回退
