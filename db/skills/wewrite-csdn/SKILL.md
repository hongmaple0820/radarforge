# CSDN 版改写

把公众号成稿转写为技术社区形态。

## 转换规则
1. **标题**：加技术关键词，去情绪词
2. **结构**：加 TL;DR 速览块置顶；section 标题带编号
3. **代码与命令**：口语描述改为代码块 + 注释
4. **去公众号腔**：金句卡片转普通段落；封面文案删除
5. **链接**：外链转脚注式引用列表

## 保留
- [n] 证据锚点与参考来源（技术社区更重出处）
- 事实与数字一字不动
